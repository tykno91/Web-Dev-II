# Web Refresher Project

## Reflection

The development of this single-page portfolio has helped refresh foundational frontend skills. The structuring of  semantic HTML elements like `<header>`, `<main>` and `<section>` was straightforward. The wiring up of a quick theme switcher in JavaScript using event listeners and DOM class toggling was also apprpriate. 

The main challenge was related to fine-tuning the layout responsiveness. It is also about getting CSS Grid to transition smoothly from a three-column desktop format into a clean single-column mobile view required careful testing within browser developer tools. 

During Web Development II, I would like to improve my JavaScript state management and component structure which will help ease the transition into frameworks like React.
